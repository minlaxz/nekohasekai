Profile config URL

{{ config_url }}

Add any param below as &name=value to change your config. "Default" is what this server uses when you leave the param out.

Required

ParamMeaning
jYour username.
kYour PSK (password).

Optional

ParamMeaningDefault
llLog level: trace, debug, info, warn, error.{{ defaults.ll or "(none)" }}
dhDoH server host or IP.{{ defaults.dh or "(none)" }}
dnDoH TLS server name (SNI).{{ defaults.dn or "(none)" }}
dpDoH path prefix. Must start with /.{{ defaults.dp or "(none)" }}
drResolver IP, used to look up the DoH host.{{ defaults.dr or "(none)" }}
ddOutbound the resolver goes through.{{ defaults.dd or "(none)" }}
dfDNS server used when no DNS rule matches.{{ defaults.df or "(none)" }}
dvIP version: 4 or 6. 6 turns on WARP (IPv6) if your account has a WARP key.{{ defaults.dv }}
rURL of your own rule set (domains to proxy). GitHub raw or gist URLs only.(none)
r6URL of a rule set listing domains to reach over WARP IPv6. Same format as r. Used only with dv=6.(none)
rdHow remote rule sets are downloaded: proxy or direct. Try direct if downloads fail.proxy

Example

{{ config_url }}&dv=6&r6=https://gist.githubusercontent.com/you/id/raw/rules-v6.json

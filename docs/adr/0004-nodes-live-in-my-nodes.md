# Tailnet service nodes live in their own repo, my-nodes

`tailscale-nodes/` (the vLLM node on EC2) and `multiplexers/` used to live here next to the proxy stack. They have a different job: they expose services as nodes on the tailnet, while this repo serves the proxy stack on the VPSs and the Profile API. They also run on different hosts (EC2 GPU, not cymric or tailless) and change for different reasons, so a vLLM change had to go through this repo's dev to master release PRs for no gain. We moved them, with the EC2 `userdata.sh`, to [minlaxz/my-nodes](https://github.com/minlaxz/my-nodes). The only contract between the two repos is the headscale control URL and a pre-auth key, both set in the node's `.env`. Consequence: this repo no longer pins the sing-box version the nodes run, and research notes here that describe the vLLM node point to my-nodes instead of local paths.

## Agent skills

### Issue tracker

Issues are tracked as GitHub Issues on `minlaxz/nekohasekai` via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at repo root plus `docs/adr/`. See `docs/agents/domain.md`.

### Concept docs

`docs/concepts/` is a beginner-readable teaching library, one term per file, no repo specifics. Index in `docs/concepts/_index.md`. When the user names a term: explain with ASCII diagrams (with/without + consequences), write the file, append to the index, commit. Do not grill.
